# 万物生：巨人的病历簿 · Giant Cure

原创 HTML5 竖屏生态疗愈小游戏，面向西山居第二届游戏创意大赛试玩。巨人的身体是一座奇幻世界；通过疏通河流、守护森林与调稳心跳，让世界重新焕发生机。

## 直接游玩

双击项目中的 **index.html**，使用 Chrome 或 Edge 打开即可。无需安装、登录、启动服务器或联网，游玩入口不依赖外部 CDN 和远程资源。

手机使用支持 JavaScript 的浏览器打开该 HTML 文件；电脑可用鼠标操作，也可调整为竖屏窗口。画面以 720×1280 为逻辑分辨率，随窗口等比适配。

## 流程与操作

翻开病历簿 → 手动选择病例或随机选择 → 开始治疗 → 查看治疗结果 → 下一病例、再次治疗或返回病历簿。

每个病例有 **90 秒**治疗时间。暂停按钮可中断治疗，继续后恢复；心跳关还可使用空格按拍。声音默认关闭，可点击右上角音符按钮开启。治愈记录保存在当前浏览器本地，清除浏览器数据会清除记录。

键盘 Esc 可暂停或继续治疗。离开浏览器页面会自动暂停；返回后点击「继续治疗」。每次治疗独立计时，不包含玩法阅读和暂停时间。三关巡诊按约 3–5 分钟设计，熟练操作会更快，实际时长还需真人试玩校准。

| 病例 | 治疗目标 | 操作与失败条件 |
| --- | --- | --- |
| 血河淤堵 | 分三批移走 9 个血栓 | 按住河中石块，拖到左侧或右侧发光的养分草地，再松手。累计 5 次误投失败；单击或取消拖拽不扣耐受。 |
| 孢子侵染 | 净化 22 颗感染孢子 | 点击紫色「感染」孢子，保护绿色「守护」精灵。误伤精灵或放任感染孢子逸散会损失生机，累计 5 次损伤失败。 |
| 心跳失序 | 完成 17 次合拍 | 光点进入金色安定区时点击画面、按拍按钮或空格。每轮只结算一次；过早、过晚或错过会失拍，累计 6 次失拍失败。 |

任一病例倒计时归零也会失败。失败后可重试；成功后可继续下一份病例。刷新页面可重新启动游戏。

## 可选开发方式

试玩只需已生成的 `index.html`。源文件按界面、主机逻辑和三个病例模块划分在 `src/` 中，方便继续修改。开发时可使用本机 Node.js 重新生成独立入口：

```sh
node scripts/bundle.js
```

修改源文件后需重新执行此命令，才能让改动进入 `index.html`。生成后的入口包含所需的样式和脚本，直接打开不需要 Node.js。

## 验证

控制器测试：

```sh
node tests/controllers.cjs
```

浏览器自动测试：

```sh
node tests/browser.cjs
```

浏览器测试需要可用的 Playwright 与 Chromium 环境。首次运行可安装可选的开发测试工具：

```sh
npm install --no-save --package-lock=false playwright
npx playwright install chromium
node tests/browser.cjs
```

也可用 `PLAYWRIGHT_PATH` 指向已有的 Playwright 包目录、`CHROME_PATH` 指向已有浏览器的可执行文件。默认使用标准 Node.js 依赖解析和 Playwright 管理的 Chromium。这些开发测试依赖不影响直接打开游戏。

## 文件结构

```text
index.html                 独立离线试玩入口（仅复制此文件也可运行）
src/index.template.html    界面结构
src/styles.css             统一绘本风格与竖屏布局
src/app.js                 导航、指针输入、计时、暂停、评分、音效、存储
src/cover.js               巨人生态岛封面绘制
src/blood.js               拖拽疏通病例
src/spore.js               点击净化病例
src/heart.js               节奏共鸣病例
scripts/bundle.js          可选的单文件生成脚本
tests/                     逻辑与浏览器回归、运行截图
```

所有画面均由本项目的 SVG / Canvas 2D 绘制；音效由 Web Audio 合成。没有远程图片、字体、声音或服务依赖。
