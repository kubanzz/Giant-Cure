# 心脏巡诊：二维横屏章节实现说明

本章以“诊断 → 分流降压 → 边躲避边治疗 → 血流冲开 → 接通传导 → 生命复苏”构成二维俯视的生态疗愈体验，首玩目标为 **3–5 分钟**。目标时长和体验效果尚待真人验证，不以自动操作时长代替。

本轮保留三个房间、三种基础工具和三个检查点。桌面键鼠是主要平台，心脏城市与纸感插画作为表现方向。肺部只在结尾求救中出现；不扩展其他器官、武器、敌人类型或 UE 系统。本目录的七份原始 3D / UE 规划保留为参考，本文件定义网页二维章节的实现口径。

## 接诊与出发

封面进入竖版森林诊所后自动连播：4 秒患病巨人扶胸走来、医生迎接；4.5 秒听诊与心肺扫描；1.5 秒初筛报告揭示。报告定位「心区血流信号减弱」，具体病因留给体内检查。患者与医生以独立头部、躯干、肢体动作绘制，人体监测 SVG 展示体积、肋骨、肺、心脏、血管与病区，心区锚点继续供入体镜头定位。

报告完成后等待玩家点击出发，随后 2 秒医疗兵检查药剂、背包并进入微缩装置，再播放原有约 1.4 秒心区推进、遮罩切换、镜头落点与 HUD 显现。完整演出约 13.4 秒，报告停留和资源等待另计。接诊不创建关卡或填写关内扫描；出发即使已创建关卡也冻结玩法，直到 `playing` 才开始接受输入和累计用时。

- 「跳过接诊」直接完成报告，保持显式出发；「跳过出发动画」改走约 200 毫秒安全淡变，仍须等待资源，不能提前进入玩法。
- 接诊演出中的帮助、后台与失焦冻结当前阶段和累计进度，必须通过「继续接诊」恢复；Esc 或返回封面离开。仅关闭帮助弹窗（如按 Esc）不会恢复接诊，点击其「继续接诊」按钮才恢复。
- 出发准备、推进、资源等待、镜头显现期间，Esc、后台或失焦取消并返回已完成的报告；返回封面则离开。token 使过期动画与资源回调失效，清空持续输入并恢复焦点。
- 减少动态效果下使用约 480 毫秒静态接诊关键帧，关闭走路、循环心电与移动扫描线；出发省略准备动作与镜头移动，统一约 200 毫秒淡变。再次进入诊断室重新接诊，档案开关保留报告。

## 章节与规则

| 状态 | 玩家行为与推进条件 |
| --- | --- |
| `diagnosis` | 对比入口正常支路与异常通路的流量、压力；扫描异常压力后可进入主血管，继续诊断血栓。正常支路扫描可选且可折返。 |
| `bypass` | 两组侧支分别依次连接 A→B；第二组末端要求舒张安全窗口。每恢复一组，血细胞改道，上游压力下降。 |
| `combat` | 一只 Hunter 教学，学习躲避扑击和扫描弱点；击败后开放治疗并加入三只干扰者。 |
| `clot` | 分别扫描、软化三处结构；前两处完成后各排队追加三只 Hunter，后续治疗与战斗同时进行。主血管最多在场四只，总预算十只。 |
| `burst` | 双侧支恢复且三处结构软化即可启动主流阀，无须清完敌人。约 4 秒冲流带走血栓与剩余 Hunter，建立主血流检查点。 |
| `conduction` | 首次进入心腔约 1.5 秒镜头揭示后恢复操作。扫描传导失序触发三只 Hunter，可在干扰下依次连接 A→B→C，无须清敌。 |
| `recovery` | 关闭心腔待刷队列；约 6 秒复苏中，1.1 秒触发首声强心跳净化剩余敌人，组织传光、灯火与植物依次恢复，随后解锁冲刺。 |
| `escape` | 循环冲刺越过出口屏障；扫描异常组织，持续治疗约 1.5 秒将其暂时压制。 |
| `ending` / `complete` | 总计 11.8 秒：0–1.8 秒暂时压制、1.8–3.8 秒再生、3.8–11.8 秒为可跳过的 8 秒巨人外景复苏，结束只结算一次。 |

扫描不耗能，也不暂停世界，优先描述症状和状态。普通目标扫描范围为 145 世界单位，血栓总诊断可在 230 单位内读取；扫描约 1.35 秒完成。常驻任务与临时反馈独立，帮助按阶段解释因果。错误连接仅清除当前序列，不扣耐久；第二侧支错过窗口时可保留首端并等待下一次舒张。提前冲流与直接射击血栓不能跳过治疗条件。

瓣膜与第二侧支只读取统一心跳。瓣膜闭合时阻挡通行，重叠时安全推回进入侧，不造成伤害；本轮不加入血流推力。侧支恢复、结构软化、血栓裂解和下游恢复都有独立可见变化。

三处结构分别扫描，每处治疗约 3.2 秒。静态结构与出口异常组织的诊断记录会保留，关闭扫描仍可治疗；Hunter 的移动弱点需要实时扫描。暂停照射、装填、躲避、暂停或失焦保留已积累的治疗进度，检查点重试则重置未完成治疗。战斗不锁回程门，可暂退入口，但不补耐久或弹药，敌人伤势与当前波次保留。

遭遇总预算上限为 13 只（主血管 10、心腔 3），预算不要求全部生成或清除。每次刷怪先显示 1 秒落点预警，相邻生成约间隔 1.2 秒；落点距医疗兵至少 280 单位，避开节点、门口、治疗点和实体墙。没有安全落点时延后，预警期间落点变得不安全则取消预警并重选。主血管/心腔在场上限分别为 4/3，每个房间最多两只同时处于扑击蓄力或扑击，起手之间至少间隔 0.55 秒。怪物绕实体墙导航并保持身体间隔。冲流关闭主血管队列并带走余敌；接通传导关闭心腔队列，首声强心跳净化余敌。

鼠标只决定方向，工具射线始终延伸至 225 世界单位，或在首个实体处停止。墙优先遮挡，首个 Hunter 承受伤害，不穿透后续敌人；确定首敌后再判断其显露弱点。已诊断且可治疗的结构允许射线进入其所在血栓，其他组织墙和前方敌人仍会阻挡；该例外不允许穿过血栓攻击敌人。绘制、命中特效、伤害和精瞄预览使用同一求交结果。

选中侧支首端后，任务显示当前回路和下一端，首端保持待连接脉冲。仅已明确的下一目标提供屏幕边缘提示；入口诊断前不提示解法。传导节点 A、B、C 分别位于 `(600,900)`、`(1180,730)`、`(780,500)`，连接中、错序、窗口等待、完成、切房与重试均重新计算提示。

## 输入、恢复与存储

- WASD 移动，Shift 疾行；鼠标瞄准，左键持续治疗或射击。右键精瞄降低移动速度，显示被首个实体截断的射线、命中点与目标类型；不吸附、不自动开火、不额外降低射速。
- Q 开关扫描，在范围内读取附近症状和弱点；E 接近后交互并连接节点；R 装填。
- Space 在复苏后解锁循环冲刺，按移动方向发动，无移动方向时使用瞄准方向。冲刺自然结束或暂停中止后均需位于可站立位置。
- 药剂匣 24 发、无限备药、发射间隔 0.2 秒、装填 1.7 秒，所有实际发射均耗药；初始耐久 100。Hunter 生命值 9，普通伤害 1，扫描弱点伤害 3；扑击预警 0.9 秒，每次命中扣 20 耐久，受伤后短暂无敌。
- 装填 0–0.45 秒为 `eject`，0.45–1.25 秒为 `insert`，1.25–1.7 秒为 `lock`，完成后回 `idle` 并补满 24 发。医疗兵手臂、药匣、背包与工具灯、角色周围进度环及 HUD 条共同反馈，分段播放退匣、插入、就绪音效；可移动，不能开火。
- 余药不超过 6 发提示低弹；空仓显示按 R 装填，并对每次持续空仓扳机提供一次音效，释放或完成装填后允许再次反馈。重复 R 不重启动作，满匣不装填；暂停冻结阶段与音效事件，检查点重试清空装填。

章节没有超时失败。耐久归零进入失败结算，玩家可以重启最近检查点。重启恢复耐久、弹匣并清空输入和装填，保留大型治疗成果，重置当前阶段敌人、未完成连接与局部治疗。

| 检查点 | 建立时机 | 保留与重试 |
| --- | --- | --- |
| `entry` | 章节开始 | 返回入口，重新诊断、分流与治疗。 |
| `bypass` | 双侧支恢复 | 保留诊断和两条侧支，重启当前遭遇与血栓治疗。 |
| `flow` | 冲流完成 | 保留分流和主血流，从心腔重新完成传导与复苏流程。 |

只有有效游玩推进累计用时、控制器和绘制时间。暂停、帮助、失焦或后台会清空持续输入并冻结心跳、相机、粒子与演出；继续后不会自动续射。失败尝试计入累计用时，重试不清零。退出、重新巡诊和刷新会创建新章节，检查点不跨会话保存。

记录继续使用 `giant-cure-journey-v1`，保存通关次数与最佳秒数，兼容已有心脏记录。不读取或迁移 `giant-cure-records-v1`。目录只统计实际可玩的心脏病例，成功一次从 `0 / 1` 变为 `1 / 1`，重复成功不增加病例数量。存储不可用时降级为正常游玩、不保存记录。声音默认关闭。

## 世界、相机与插画

治疗页为 **1280×720**，世界窗口为 `{ x:24, y:84, w:1232, h:552 }`；封面、诊断室、病例档案和结算仍为 **720×1280**。页面切换和窗口缩放同步更新逻辑尺寸、CSS 尺寸及 Canvas 两个 backing 维度，DPR 适配最高为 2。1366×768 下任务与关键扫描结论至少 14 CSS 像素，边缘目标标签完整显示。

入口与主血管的世界尺寸为 1600×1000，心腔为 1800×1200，均超出常态视野。控制器提供世界坐标几何与房间边界，碰撞、交互提示、绘制和测试定位共用这些数据。HUD 使用屏幕坐标，上下边缘显示任务、反馈、扫描、心跳、耐久与工具。

主机维护共享视图：

```js
view = {
  viewport: { x: 24, y: 84, w: 1232, h: 552 },
  camera: { x, y, zoom }, // x / y 为世界中心
  reducedMotion // 主机调用 draw 时传入的布尔值
};
```

世界投影为 `screen = viewport.center + (world - camera.center) * zoom`。指针先从浏览器位置换算为当前逻辑屏幕坐标，再逆变换为世界坐标。相机更新后，每帧重新换算静止指针；窗口缩放后也重新换算。HUD 和世界窗口外的按下不开始治疗，窗口外释放仍会清除持续操作。

普通移动、战斗和治疗使用轻量跟随，默认 `zoom=1.1`，相机限制在世界边界内。房间切换与检查点重试立即定位；短揭示、冲流、复苏和结尾读取控制器的 `cameraCue`，不在普通战斗中抢镜。减少动态效果模式使用静态构图切换与明暗变化。世界粒子使用同一视图变换和裁剪，结算屏幕粒子单独绘制。

运行时八张插画放在 `assets/heart-journey/`：`entry/main/heart/exterior/clinic/recoveryValley/recoveryGiant/recoveryEyes`，提示词保留在同目录 `prompts.json`。诊所使用暖纸色森林背景，患者、医生、医疗兵与微缩装置为程序动作；游戏中的小医疗兵有医疗头盔、面部、白绿制服、背包、独立手臂和靴子，上身瞄准与腿部移动分离，持医疗工具。节点、瓣膜、血栓、血流与灯火仍为程序交互，不依赖底图画死的目标。

组织地面自由行走，血管表现为贴地的浅流槽，可跨越；连续曲线和局部粗细变化共用于槽体、血细胞和扫描流向。主血管扩大为两处 170×150 组织岛并加入横向组织肋，心腔中央岛为 220×130，压缩直线路径并提供可绕行掩体。高起组织墙同时阻挡移动与射击，其绘制轮廓、碰撞、敌人导航和射线遮挡共用几何；外围连续组织边缘明确边界。血栓软化时纤维松散、裂缝展开、表层剥离，冲流前仍保持实体轮廓。

每个传导节点附近均有灯窗和植物，衰弱时暗淡静止，6 秒复苏中依次亮起、舒展并读取统一心跳。复苏镜头覆盖附近变化，结束平稳返回玩家。诊断栏实时区分未诊断、连接中、复苏中、稳定与异常再生。

结尾外景使用固定山谷层、可局部变形的巨人层和睁眼局部图层。8 秒内依次表现深呼吸、缓慢睁眼与手指舒展、树梢轻动、鸟群飞起、村落亮灯，最后提示心脏稳定与肺部求救；山谷不随巨人身体变形。减少动态效果用稳定构图和轻微姿态/明暗变化。外景隐藏耐久、药剂匣、工具与旧扫描信息，仅保留暂停、声音、叙事字幕和跳过。跳过将剩余模拟时间推进到同一完成态，累计用时包含该段，仍只结算一次。

`window.GiantCureAssets` 暴露 `images`、`ready`、`error`、`clinicError`、`recoveryError` 和 `retry()`，`images` 使用上述八个键。启动预载，出发在遮罩下等 `ready`，必要房间插画失败恢复报告并提供重试或返回。诊所图失败只记 `clinicError`、回退程序背景；任一复苏层失败只记 `recoveryError`、回退原 `exterior`，不阻断游戏。档案直接出诊保持约 250 毫秒淡变。构建内联全部运行时图片、脚本与样式，单文件离线游玩不请求外部资源。

## 主机与控制器接口

控制器注册于 `window.GiantCureGames.heartJourney(api)`：

| 回调 | 约定 |
| --- | --- |
| `progress(value)` | 发布 0–1 的治疗进度。 |
| `setTask(text)` | 发布持续显示的当前问题和目标。 |
| `feedback(text, kind)` | 发布短时操作反馈，不覆盖任务。 |
| `hud(data)` | 发布耐久、弹药、`reloadRemaining/reloadProgress/reloadStage`、扫描、阶段、房间、检查点、重试与冲刺状态。 |
| `effect(x, y, color, count)` | 发布世界坐标粒子，由主机统一变换、裁剪和暂停。 |
| `sound(name)` | 默认静音的共享通道，支持心跳、冲流、命中，以及 `reloadOut/reloadIn/reloadReady/empty`。 |
| `success()` / `fail(reason)` | 交给主机结算；控制器防止重复触发。 |

返回接口为 `update(dt)`、`draw(ctx, activeTime, view)`、`pointerDown/Move/Up/Cancel`、`keyDown(code, repeat)`、`keyUp(code)`、`clearInput()`、`retryFromCheckpoint()` 和 `getDebugState()`。键码使用 `KeyboardEvent.code`；指针数据为世界坐标，右键为 `button:2`。

控制器只维护一个 `heartbeatClock`。`beat()` 给出 `phase/pulse/safe/state/period`，第二侧支、瓣膜、血流、城市和灯光读取同一快照。跨拍触发声音，长帧不集中补播历史心跳；复苏第一声强心跳由阶段事件触发。

绘制模块为 `window.GiantCureJourneyArt.draw(ctx, snapshot, activeTime, view)`，只读快照并负责世界裁剪、变换和绘制，不计算治疗结果。`activeTime` 由主机推进，暂停时不使用仍在流逝的墙上时钟。主机通过 `view.reducedMotion` 传递动态效果偏好；外景身体、眼部、树冠、飞鸟与灯光均使用 `exteriorRecovery.elapsed`，胸口亮度读取统一心跳。

诊所绘制为 `window.GiantCureClinicArt.draw(ctx, clinic, elapsed, images)`，准备演出为 `drawPreparation(ctx, progress)`。诊所演出只读取主机累计进度，暂停时人物和步态不继续运动。

`getDebugState()` 返回冻结的深拷贝，含世界尺寸、边界、房间、玩家、工具、节点、门口、碰撞物、瓣膜、路径、敌人、血栓结构、传导、异常组织、心跳和检查点；`cameraCue` 提供 `kind/target/progress`，首次心腔揭示有 `revealRemaining`。测试通过公开输入驱动玩法，不能修改快照跳关。

`toolPreview` 为只读射线结果，提供 `from/to/kind/hitType/targetId/weakpoint/blocked/label/range`，即使未按右键也可供回归检查；`shot` 使用同一字段并增加 `age`。`guidance` 为当前明确连接的 `kind/label/text/source/target/waiting`，没有已知下一目标时为 `null`。渲染不另算命中与连接规则。

`player.velocity/moving/walkDistance` 驱动实际步态；`reloadProgress` 为装填期间 0–1、闲时 0，`reloadStage` 为 `idle/eject/insert/lock`。`encounter` 为当前房间、`encounters` 为房间映射，包含 `room/alive/pending/budget/spawned/cap/closed/triggered`；`spawnTelegraphs` 为当前房间待刷点，含位置、半径、剩余秒数和 0–1 进度。`endingDuration=11.8`，`exteriorRecovery={elapsed,duration:8,progress}` 是独立外景进度快照；均不能通过改写来跳关。

主机 `window.GiantCure.snapshot()` 追加复制后的 `view/logicalSize/reducedMotion/particles/activeTime`。`clinic` 提供 `phase`（`idle/arriving/examining/report/ready`）、累计演出秒数 `elapsed` 和 `paused`，正常完成为 10 秒、减少动态效果完成为 0.48 秒。`diagnosis.phase` 仍为 `idle/scanning/ready`，到诊与检查映射 `scanning`，报告开始映射 `ready` 并关联 `heartJourney`；可出发还要求 `clinic.ready`。`transition.phase` 为 `idle/preparing/departing/waiting/arriving`，与 `caseId` 一同只读返回；过场中的病例为 `heartJourney`，结束或取消后为 `null`，完成后才进入 `playing`。UI 跳过按钮操作主机流程，不暴露可变快照或跳关接口。
