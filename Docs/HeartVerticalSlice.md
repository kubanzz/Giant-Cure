# Giant Cure — Heart Vertical Slice Design v1

## 1. 验证目标

Heart Slice 不是第一章最终版，而是用最低成本验证 Giant Cure 是否值得正式制作。

必须验证：
1. 巨人体内尺度感成立。
2. FLOW 血栓治疗成立。
3. Scanner / Treatment Tool / Biological Link 三核心工具成立。
4. 癌细胞弱点战斗自然融入治疗。
5. 心脏恢复产生强烈反馈。
6. 玩家愿意继续进入肺部。

## 2. 预计时长

首次：12–15 分钟  
熟练：8–10 分钟

## 3. 空间结构

```text
Medical Entry
  ↓
Entry Vessel
  ↓
Observation Bend
  ↓
Main Vessel Junction
  ↓
Blocked Artery / Thrombus
  ├── Bypass A
  └── Bypass B
  ↓
Thrombus Treatment Zone
  ↓
Heart Chamber
  ↓
Conduction Nodes
  ↓
Heart Recovery
  ↓
Exit / Cancer Foreshadowing
```

主要空间约 7 个。

## 4. 逐段流程

### Segment 1 — Entry Vessel（00:00–01:30）
- 建立第一人称移动
- 体验巨大血流
- 听到微弱心跳
- 用 Low Flow Zone 教玩家血流危险
- 只教 Move / Look / Jump

### Segment 2 — First Diagnosis（01:30–03:00）
- 血流明显减弱
- 提示 Q 开启 Scanner
- Scanner 显示 FLOW RATE ↓ / PRESSURE ↑
- 不显示具体血栓目标点

### Segment 3 — Tracking the Problem（03:00–05:00）
- Main Vessel Junction 三向选择
- 通过 Scanner 判断异常方向
- 穿越周期性瓣膜
- 教会“器官本身就是环境机关”

### Segment 4 — Thrombus Reveal（05:00–06:00）
- 巨型血栓堵塞血管
- Scanner 确认 THROMBUS
- 直接强攻导致碎片脱落与 Secondary Obstruction Warning
- 玩家学到“不能直接射爆”

### Segment 5 — Restore Bypass Flow（06:00–09:00）
- 恢复 Bypass A：教学 A→B Biological Link
- 恢复 Bypass B：加入心跳/压力安全窗口
- 完成后 Bypass Flow 100%
- 主堵塞区域压力下降

### Segment 6 — First Cancer Combat（09:00–10:30）
- UNKNOWN CELLULAR ANOMALY 受刺激
- 1→2→最多 3 只 Hunter Cancer Cell
- Scanner 显示弱点
- 建立 Scan → Weakpoint → Shoot
- 不做锁门清怪房

### Segment 7 — Thrombus Treatment（10:30–12:00）
- 扫描三个 Structural Weak Points
- Treatment Tool 软化结构
- Clot Stability 逐步下降
- 启动 Main Flow Burst
- 巨大血流冲开血栓
- PRIMARY FLOW RESTORED

### Segment 8 — Heart Rhythm Failure（12:00–14:00）
- 血流恢复但 HEART RATE STILL CRITICAL
- 进入巨大 Heart Chamber
- 扫描 ELECTRICAL CONDUCTION FAILURE
- 使用 A→B→C Biological Link 修复三个传导节点
- 无战斗，降低节奏

### Segment 9 — Heart Recovery（14:00–15:00）
- 短暂无声
- 巨大心跳恢复
- 血流、瓣膜、颜色、声场全面恢复
- HEART RHYTHM RESTORED / HEART STATUS STABLE

### Segment 10 — Ability Unlock
- CIRCULATORY LINK ESTABLISHED
- 解锁 Circulatory Boost / Dash
- 立即用一次 Dash 通过小障碍

### Ending Foreshadowing
- 再次发现 UNKNOWN CELLULAR ANOMALY
- 普通治疗暂时压制，但轻微再生
- 镜头切到巨人外部：胸口重新明显搏动
- NEXT CRITICAL SYSTEM: RESPIRATORY

## 5. 三个必须打磨的 Moment

1. **进入 Heart Chamber**：负责 WOW。
2. **血流冲开血栓**：负责 Gameplay Payoff。
3. **心脏重新强烈搏动**：负责 Emotional Payoff。

## 6. Blind Playtest 重点

- 玩家能否明确说出“我在心脏里”。
- 是否能借 Scanner 找到血栓。
- 是否理解不能直接攻击血栓。
- 冲开血栓是否 ≥ 4/5 满足感。
- 弱点战斗是否有意义。
- 心脏恢复是否有“救活了一部分身体”的感觉。
- 是否愿意继续玩肺部。
