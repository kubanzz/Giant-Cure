## 通关后提问与观察

1. “你认为这颗心脏出了什么问题？你的操作怎样改变了它？”记录玩家原话。
2. “你选择了哪条侧支？它畅通后发生了什么？”记录安全 / 速度取舍、压力变化和补给运输是否被看懂。
3. “为什么处理血栓外层和核心要换工具？血流恢复后，为什么还要继续检查？”记录针对工具与第二次诊断的理解。
4. “你怎样判断传导故障在哪，怎样确认修好了？”合格答案包含输入 / 输出或脉冲中断对比，以及修复后到达下游，不要求医学术语。
5. “哪一段最让你感到治疗起效？冲流与复苏分别打几分？”记录具体画面或声音依据。
6. “出口组织发生了什么？你愿不愿意继续去肺部？”记录再生是否被看懂及继续意愿。

观察重点：扫描进度与距离是否清楚，是否比较侧支路线，是否能区分浅流槽和实体墙；是否理解近距扇形与远距射线、遮挡、恢复期弱点及自动装填。记录先清敌 / 抢治疗的选择理由，补给运输、外层剥离、核心暴露、故障输入 / 输出差异和三拍复测是否被注意。不能提前提示“选哪条路”或“故障在何处”。
